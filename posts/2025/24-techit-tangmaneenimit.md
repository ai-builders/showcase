- ChronoCall-Q  เป็นโปรเจคที่พัฒนาโมเดล Qwen3 ผ่านการ Fine-tune โดยมีเป้าหมายให้โมเดลเข้าใจคำสั่งของผู้ใช้เกี่ยวกับการจัดการตารางเวลา (Scheduling) เช่น การเพิ่ม ลบ แก้ไข และดูนัดหมาย โดยเชื่อมต่อกับ Google Calendar ซึ่งมีเป้าหมายเพื่อเพิ่มประสิทธิภาพในการจัดการเวลาห้กับผู้ใช้งาน
- ชุดข้อมูลที่เอาไป Fine-tune รวบรวมมาจากแบบสอบถามบน Google Form ให้คนทั่วไปช่วยเขียนประโยคคำสั่งที่ใช้จริง เช่น "นัดหมอตอนเย็นวันพฤหัส" หรือ "ประชุมบ่ายสองพรุ่งนี้" จากนั้นนำประโยคพวกนี้มาเขียนโค้ดใส่ วันที่ เวลา และคำพวก "วันนี้", "พรุ่งนี้", "อาทิตย์หน้า" และกำหนด tool ที่โมเดลควรเรียกใช้ในแต่ละประโยคลงไป เพื่อให้โมเดลเข้าใจคำสั่งที่มนุษย์ใช้พูดจริง ๆ
- ได้ชุดข้อมูลทั้งหมด 2,946 ประโยค แบ่งเป็น Training set 70%, Validation set 20% และ Test set 10%
- นำมา Finetune ด้วย LoRA (Low-Rank Adaptation) โดย Model ที่นำมา Finetune คือ Qwen3-4b และ Qwen3-0.6b(สำหรับ Deploy)
- หลังจากนั้นเอามาวัดผลก่อน-หลังด้วยข้อมูลใน Test set โดยแบ่งเป็น Action Accuracy , Date Accuracy , Time Accuracy และ Total Accuracy (all fields match) เพื่อวัดว่าโมเดลเรียกใช้งานคำสั่งได้ถูกต้องขนาดไหน
- ซึ่งหลังจาก Finetune เสร็จก็พบว่าโมเดลมักจะมีปัญหาเกี่ยวกับการบอกวันที่ ซึ่งส่วนใหญ่จะเป็นคำเชิง relative date เช่น “ศุกร์หน้า”, “เสาร์หน้า”
- โมเดลยังมีปัญหาในการสรุปหรือเลือกข้อความที่เหมาะสมสำหรับใช้เป็นหัวข้อ (title) ของกิจกรรมใน Google Calendar ซึ่งอาจทำให้ชื่อกิจกรรมไม่สื่อถึงสิ่งที่ผู้ใช้ต้องการจริง ๆ
- เนื่องจากข้อมูลที่ใช้ในการฝึกส่วนใหญ่เป็นภาษาพูดสุภาพในบริบททั่วไป โมเดลจึงอาจตีความคำสั่งที่ใช้ภาษาหยาบคายหรือไม่เป็นทางการได้ไม่ถูกต้อง
